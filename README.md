# 钟馗志

《黑神话：钟馗》非官方中英双语资料聚合站，集中整理官方消息、视频原片、画面观察、人物考据和海外讨论。每条资料保留原始出处，并区分官方确认、有限观察、创作者观点与玩家反应。

网站：<https://zk.syal.site>

## 自动更新

仓库每天通过 GitHub Actions 运行一次受限的内容采集：

1. 使用 NVIDIA NIM 上的 `deepseek-ai/deepseek-v4-flash` 处理资料，运行上下文按 280,000 tokens 配置，使用流式响应。
2. 由脚本直接调用 Exa 的匿名免费 MCP，按固定查询计划搜索近期一手消息与高价值解读；搜索不依赖模型自行触发。
3. 当前每轮固定执行 16 次跨来源搜索，硬上限 200 次，只选择最多 10 条新资料。
4. 对检出的 B站、YouTube 视频尝试读取公开元数据与字幕：只有接口确实返回字幕正文时才交给模型；登录限制、YouTube PO Token 限制和未提供字幕都会明确标记，不能被写成“已提取字幕”。
5. 单轮模型费用按 NVIDIA API 响应中的 token usage 与保守影子费率估算，上限 10 CNY；整个采集任务限时 1 小时。
6. 搜索证据先压缩到固定载荷内，再直接交给 NVIDIA 的流式接口；模型只能返回双语 JSON，没有仓库工具或写文件权限。
7. 独立脚本验证中英文字段、受众范围、来源、去重、证据等级、数据格式和文件改动范围。
8. 验证通过后，独立发布任务只提交 `content/state.json`、一个自动内容条目和生成数据；UI、样式与手工核心档案不在自动更新权限内。

中文界面优先展示官网、B 站和国内可访问文章；英文界面优先展示多个独立 YouTube 创作者与海外媒体。高价值视频可交叉展示，但每批数据会强制保持中文 B 站与英文 YouTube 至少 2:1 的主平台比例，并限制同一 YouTube 频道在单轮重复。人物志会按人物名和身份标签自动关联后续新增的视频与文章，因此日常维护只需更新结构化数据。

远程仓库只保留运行网站和自动更新所需的源码、内容数据、配置、工作流以及本 README。原始模型会话、搜索结果全文、运行日志、内部报告、本机路径和凭据不会提交。

> 10 CNY 是运行时门槛：流中有 usage 时按 NVIDIA 返回值计算，没有 usage 时按上下文和最大输出的保守上界在请求前拦截。这不是模型服务商账户的账单级硬限额；若需要绝对账户限额，还应在模型服务商控制台设置消费上限。

## 内容标记

- `官方确认`：来自官网、官方账号、官方文案或游戏界面中的明确文字。
- `画面观察`：可以回到原片复核的画面信息，以及明确归属于作者的有限分析。
- `社区推测`：尚无官方结论的解释，不进入无人值守的自动发布通道。
- `玩家反应`：观看体验和观点，不作为游戏机制证据。

本站为个人兴趣项目，与游戏科学、哔哩哔哩、YouTube 及其他内容平台无隶属关系。游戏名称、官方画面和平台标识的权利归各自权利人所有。
