# 钟馗志

《黑神话：钟馗》非官方中英双语资料聚合站，集中整理官方消息、视频原片、画面观察、人物考据和海外讨论。每条资料保留原始出处，并区分官方确认、有限观察、创作者观点与玩家反应。

网站：<https://zk.syal.site>

## 自动更新

仓库每天通过 GitHub Actions 启动固定版本的 DeepSeek Harness：

1. 使用 NVIDIA NIM 上的 `minimaxai/minimax-m3` 处理资料，运行上下文按 280,000 tokens 配置。
2. 通过 Exa 的匿名免费 MCP 搜索近期一手消息与高价值解读。
3. 单轮搜索不超过 200 次，只选择最多 10 条新资料。
4. 单轮模型费用按 DSH 暴露的 token usage 与保守影子费率估算，上限 10 CNY；整个采集任务限时 1 小时。
5. DSH 只能生成临时双语 JSON 草稿，没有 Git 写权限。
6. 独立脚本验证中英文字段、来源、去重、证据等级、数据格式和文件改动范围。
7. 验证通过后，独立发布任务只提交 `content/state.json`、一个自动内容条目和生成数据；UI、样式与手工核心档案不在自动更新权限内。

远程仓库只保留运行网站和自动更新所需的源码、内容数据、配置、工作流以及本 README。原始模型会话、搜索结果全文、运行日志、内部报告、本机路径和凭据不会提交。

> 10 CNY 是依据 DSH 可读取 usage 与仓库内保守费率计算的运行时门槛，不是模型服务商账户的账单级硬限额。若需要绝对账户限额，还应在模型服务商控制台设置消费上限。

## 内容标记

- `官方确认`：来自官网、官方账号、官方文案或游戏界面中的明确文字。
- `画面观察`：可以回到原片复核的画面信息，以及明确归属于作者的有限分析。
- `社区推测`：尚无官方结论的解释，不进入无人值守的自动发布通道。
- `玩家反应`：观看体验和观点，不作为游戏机制证据。

本站为个人兴趣项目，与游戏科学、哔哩哔哩、YouTube 及其他内容平台无隶属关系。游戏名称、官方画面和平台标识的权利归各自权利人所有。
